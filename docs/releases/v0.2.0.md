# Release v0.2.0

Minor feature release for `pagewise-pdf-extractor`.

## Summary

This release preserves richer PDF layout structure alongside extracted page Markdown. Page results and `progress.json` now include `layout_artifacts` for tables, figures/images, and vector drawings where providers can detect them.

## Added

- Public `LayoutArtifact` model.
- `layout_artifacts` on `PageExtractionResult`.
- PyMuPDF layout artifact extraction for tables, figures/images, and vector drawings.
- Markdown-derived table and figure artifacts for Marker and Ollama output.
- Layout artifact rendering in page Markdown output.

## Install

From PyPI:

```powershell
python -m pip install pagewise-pdf-extractor==0.2.0
```

From GitHub:

```txt
pagewise-pdf-extractor @ git+https://github.com/ebmurha/pagewise-pdf-extractor.git@v0.2.0
```

## Validate

```powershell
pagewise-pdf-extractor --validate-environment
```
