# Release v0.1.0

First valid integration release of `pagewise-pdf-extractor`.

## Summary

`pagewise-pdf-extractor` converts PDFs into page-wise Markdown for downstream RAG and document-processing systems. It handles text-native pages, scanned pages, mixed documents, provider fallback, progress tracking, and structured extraction results.

## Highlights

- Installable Python package with import package `pagewise_pdf_extractor`.
- CLI entrypoint: `pagewise-pdf-extractor`.
- Public API: `ExtractionConfig`, `ExtractionResult`, `process_pdf`, `validate_environment`.
- PyMuPDF provider for embedded text extraction.
- Marker provider for scanned-page OCR.
- Ollama fallback provider for vision OCR.
- One Markdown file per page with a stable page wrapper.
- Versioned `progress.json` with source hash, config hash, provider attempts, and page statuses.
- SHA-256 output directories to avoid same-stem collisions.
- Same-output lock to prevent concurrent runs from sharing files.
- Developer documentation for API, configuration, environment setup, integration, packaging, and release workflow.

## Install

```txt
pagewise-pdf-extractor @ git+https://github.com/ebmurha/pagewise-pdf-extractor.git@v0.1.0
```

## Validate

```powershell
pagewise-pdf-extractor --validate-environment
```

## Notes

OCR provider binaries are not bundled. Operators must install and expose `marker_single`, `ollama`, and `pdftoppm` where those provider paths are required.
