# Release v0.1.1

PyPI publication release of `pagewise-pdf-extractor`.

## Summary

This release publishes the first public package build to PyPI after the original `v0.1.0` Git tag was created before the publishing workflow was available.

The package behavior is the same early integration surface documented for `v0.1.0`.

## Install

From PyPI:

```powershell
python -m pip install pagewise-pdf-extractor==0.1.1
```

From GitHub:

```txt
pagewise-pdf-extractor @ git+https://github.com/ebmurha/pagewise-pdf-extractor.git@v0.1.1
```

## Validate

```powershell
pagewise-pdf-extractor --validate-environment
```
